* Purpose

Android has deliberately separate Emacs environments instead of loading the full desktop Doom configuration everywhere.

The lightweight native Android reader lives in =../android/= and remains a read-first StarIntel research client.  It provides research synchronization, a minimal gptel setup, touch controls, document review, and Org-roam without loading the development stack.

The Termux development profile lives in =../android/doom/= and is a real Doom profile with its own =config.org=.  It focuses on StarIntel administration, Org editing/agenda/TODOs, SWI-Prolog, SBCL, Nim, Python, shell workflows, and AI access.  It is launched with =emacs-termux= after running the Termux bootstrap.

The older Temple Android configuration remains available through the existing =temple= Chemacs profile, which sets =TEMPLE_MODE=active=.
