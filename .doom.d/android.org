* Purpose

The canonical Android configuration lives in =../android/= and is deliberately
separate from the full Doom desktop configuration.

The default native Android Emacs profile is a read-first StarIntel research
client.  It provides:

- synchronization of every non-archived =lost-rob0t= repository whose name
  contains =auto-research=;
- the shared desktop gptel OpenRouter configuration and gptel personas without
  loading the desktop agent/image/MCP stack;
- a touch-first text toolbar;
- an unreviewed-document dashboard sorted newest first;
- a newest-first indexes section;
- Org-roam through =starintel-auto-research/lisp/starintel/second-brain.el=.

The old Temple Android configuration remains available through the existing
=temple= Chemacs profile, which sets =TEMPLE_MODE=active=.  Normal Android
sessions do not load Temple, Evil, Prolog, Magit, vterm, or other development
packages.
