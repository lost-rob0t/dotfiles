# logos

NixOS 26.05 workstation and installer configuration for `logos`.

## Build

```sh
nix flake check
nix build
nix build .#logos-iso
```

The installer ISO is written under `result/iso/`.

## Publish an installer

Run the **Publish Logos ISO** workflow manually and provide a release tag such
as `logos-2026.07.1`. The workflow builds the ISO from that Git commit and
attaches the raw `.iso` and its SHA-256 checksum to a GitHub Release.

## Install

Boot the Logos ISO in UEFI mode, connect to the network, identify the target disk
with `lsblk`, then run:

```sh
sudo install-logos /dev/nvme0n1
```

The command is destructive and requires typing the exact device path and
`WIPE-LOGOS` before it modifies the disk.

The provisioned layout is:

- 1 GiB EFI system partition
- one LUKS2 partition using all remaining space
- one Btrfs filesystem inside LUKS
- `@`, `@home`, `@nix`, `@log`, and `@snapshots` subvolumes

Root, home, and the Nix store therefore share the same free-space pool instead
of being trapped in fixed-size partitions.

The active host retains Docker and enforces assertions against libvirt, Steam,
and Sunshine.
