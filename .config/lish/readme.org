#+title: Lish Agentic Shell

Lish is the default interactive shell surface for these dotfiles.

The base shell is Yew/Lish running in SBCL.  The dotfiles layer adds:

- native Common Lisp + normal shell command execution;
- automatic routing of otherwise-unknown/free-form input to Prolog-RLM;
- explicit =ai=, =ask=, =agent=, =shell=, =lisp=, and =oneliner= commands;
- =direct=, =symbolic=, =symbolic-recursive=, and =auto= reasoning modes;
- LISA loading in the same Common Lisp image;
- repo-local Zara/Prolog expert discovery/test/query tooling;
- a Bash recovery shim (=STAR_BASH_FALLBACK=1=);
- matching Home Manager and Termux deployment.

See [[file:../../docs/wiki/lish.org][docs/wiki/lish.org]] for the architecture and commands.
