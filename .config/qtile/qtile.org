#+title: Qtile Configuration

* Canonical configuration
The active Qtile configuration is [[file:config.py][config.py]].

This file previously duplicated the complete Python configuration and tangled it into =config.py=. The two copies had drifted and the literate copy retained the same runtime bugs as the generated file. The duplicate source has been retired so future fixes and features have one canonical implementation.

Edit =config.py= directly.

* Automatic group mode
The first button on each top bar displays either =AUTO:OFF= or =AUTO:ON=.

Left-clicking the button enables or disables automatic group management.

When enabled:
- Existing mapped windows are immediately moved to their configured groups.
- New mapped windows are moved to their configured groups.
- Moving a mapped window to another normal group is automatically corrected.
- Groups with more than three windows use the =max= layout.
- Groups with three or fewer windows return to their configured default layout.
- Scratchpad windows are excluded.

When disabled, Qtile stops enforcing routes and layout thresholds. Existing windows and layouts are left in their current state so they can be rearranged manually.

Application routes are configured in =auto_group_routes= in =config.py=.

* Validation
Run these checks after modifying the configuration:

#+begin_src sh
python -m py_compile config.py
qtile check -c config.py
#+end_src

The second command requires Qtile to be installed in the current environment.
