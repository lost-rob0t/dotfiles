* Startup & Autostart
:PROPERTIES:
:DESCRIPTION: Programs to run when Qtile starts
:DEPENDENCIES: Requires autostart.sh and setup-monitors.sh in ~/.config/qtile/scripts/
:END:

** What Gets Started
- *startup_once*: Runs ONCE when Qtile first starts (per session)

** Monitor profile
Qtile applies the monitor profile synchronously while loading the
configuration, before screen and bar objects are created. The selector
chooses the executable profile named
=$USER@$HOSTNAME.sh= under =scripts/monitors/=, so each host keeps its own
output layout without putting monitor setup in =autostart.sh= or =.xinitrc=.
The process-level guard prevents a normal in-process config reload from
re-running =xrandr= while Qtile is rebuilding its bars; a fresh Qtile process
runs the profile again.

** Expected autostart.sh contents
Your script should handle:
- Setting wallpaper
- Starting compositors (picom)
- System tray applications
- Any background services

* Scratchpad System

** What are Scratchpads?
Floating windows that appear/hide on keypress.
Think of them as "quake-style" dropdowns for ANY application.

** Available Scratchpads
1. *Terminal* (F12): Quick terminal access
2. *Browser* (Mod+Shift+F1): Nyxt browser for quick lookups
3. *Emacs* (Mod+Shift+E): Floating Emacs frame
4. *Org Capture* (Mod+X): Quick note taking
5. *KeePassXC* (Mod+F3): Password manager
6. *Media* (Mod+Shift+M): Music player (Sonixd)
7. *Audio* (Mod+V): Pavucontrol mixer

** Technical Notes
- Windows are 80% screen size, centered
- ~on_focus_lost_hide=False~ means they stay visible when clicking elsewhere
- Match by title/wm_class to ensure correct window is controlled

** Auto-Assignment Logic
When Auto mode is enabled, Qtile checks its WM_CLASS and title and moves
AI-related windows to workspace 3, Discord to workspace 9, games to workspace
4, and video players or video-site tabs to workspace 6. It also reorganizes
newly managed windows while leaving already-open windows alone.

The AI patterns come from the local ActivityWatch window bucket: ChatGPT
Desktop, ChatGPT/Agent Zero/OpenRouter/Claude tabs in Brave, T3 Code, Emacs
LLM/OpenRouter/MCP buffers, OpenAI Firefox tabs, and OpenCode/Claude Code
Terminator titles. ActivityWatch also identified Steam/PrismLauncher,
Minecraft, War Thunder, YouTube, Twitch, and Feishin windows for the game and
video routes. Normal Brave pages and ordinary terminal windows remain where
they are.

** Finding WM_CLASS
Run ~xprop~ in terminal, then click a window to see its WM_CLASS.
Use the FIRST field in WM_CLASS(STRING) for matching.

** Floating Window Rules
Some windows should ALWAYS float (dialogs, popups, etc.).
Matching is done by WM_CLASS or window title.

def apply_auto_grouping(window):
    """Move a managed window only while Auto mode is enabled."""
    if not auto_group_mode or not getattr(window, "group", None):
        return
    if window.group.name not in group_names:
        return
    target = routed_group(window)
    if target and window.group.name != target:
        source = window.group.name
        from qtile_telemetry import telemetry_auto_route
        telemetry_auto_route(window, source, target)
        follows_focus = window is getattr(window.qtile, "current_window", None)
        window.togroup(target, switch_group=follows_focus)
    update_auto_layouts(window.qtile)


def organize_existing_windows(qtile):
    """Apply the same routes to windows already managed by Qtile."""
    for group_name in group_names:
        group = qtile.groups_map[group_name]
        for window in tuple(group.windows):
            target = routed_group(window)
            if target and target != group_name:
                from qtile_telemetry import telemetry_auto_route
                telemetry_auto_route(window, group_name, target)
                window.togroup(target, switch_group=False)
        update_group_layout(group)
    update_auto_layouts(qtile)

# === WINDOW TO SCREEN FUNCTIONS ===

@lazy.function
def window_to_prev_group(qtile):
    """Move focused window to previous workspace."""
    if qtile.currentWindow is not None:
        i = qtile.groups.index(qtile.currentGroup)
        qtile.currentWindow.togroup(qtile.groups[i - 1].name)

@lazy.function
def window_to_next_group(qtile):
    """Move focused window to next workspace."""
    if qtile.currentWindow is not None:
        i = qtile.groups.index(qtile.currentGroup)
        qtile.currentWindow.togroup(qtile.groups[i + 1].name)

def window_to_previous_screen(qtile, switch_group=False, switch_screen=False):
    """
    Move window to previous screen.

    Args:
        switch_group: Move workspace to that screen
        switch_screen: Move focus to that screen
    """
    i = qtile.screens.index(qtile.current_screen)
    if i != 0:
        group = qtile.screens[i - 1].group.name
        qtile.current_window.togroup(group, switch_group=switch_group)
        if switch_screen:
            qtile.cmd_to_screen(i - 1)

def window_to_next_screen(qtile, switch_group=False, switch_screen=False):
    """
    Move window to next screen.

    Args:
        switch_group: Move workspace to that screen
        switch_screen: Move focus to that screen
    """
    i = qtile.screens.index(qtile.current_screen)
    if i + 1 != len(qtile.screens):
        group = qtile.screens[i + 1].group.name
        qtile.current_window.togroup(group, switch_group=switch_group)
        if switch_screen:
            qtile.cmd_to_screen(i + 1)

** Window Swallowing
When you launch a GUI program from terminal, the terminal window
is hidden until you close the GUI program. Keeps workspace clean!

** How It Works
1. New window opens → get its parent process ID
2. Check if parent is a terminal
3. If yes, minimize the terminal
4. When GUI closes, restore the terminal

** Mouse Bindings
- *Mod+LeftClick+Drag*: Move floating windows
- *Mod+RightClick+Drag*: Resize floating windows

# === WINDOW SWALLOWING FEATURE ===

@hook.subscribe.client_new
def _swallow(window):
    """
    Hide the terminal that launched a GUI application.

    Example: Running 'firefox' from terminal will hide the terminal
    until Firefox is closed.

    Requires: psutil library
    """
    pid = window.window.get_net_wm_pid()
    ppid = psutil.Process(pid).ppid()
    cpids = {
        c.window.get_net_wm_pid(): wid
        for wid, c in window.qtile.windows_map.items()
    }

    # Check up to 5 parent processes
    for i in range(5):
        if not ppid:
            return
        if ppid in cpids:
            parent = window.qtile.windows_map.get(cpids[ppid])
            parent.minimized = True
            window.parent = parent
            return
        ppid = psutil.Process(ppid).ppid()

@hook.subscribe.client_killed
def _unswallow(window):
    """Restore the terminal when swallowed window closes."""
    if hasattr(window, 'parent'):
        window.parent.minimized = False

** Common Issues

*** Java Applications Not Rendering
If Java apps show gray/blank windows, ensure ~wmname = "LG3D"~ is set.
See: https://archive.is/DOJvD

*** Thermal Sensor Not Working
- AMD CPUs: Use ~thermalTag = "Tctl"~
- Intel CPUs: Use ~thermalTag = "Package id 0"~
- VirtualBox/VMs: Comment out ~ThermalSensor~ widget

*** Weather Widget Shows Wrong Location
The widget uses your external IP for geolocation.
Update ~myIp~ by modifying ~/.local/share/ip

** Performance Tips

*** Reduce Widget Update Frequency
- Lower ~update_interval~ values for widgets
- Comment out unused widgets (especially graphs)

*** Optimize for Pentesting
- Keep terminal scratchpad readily available (F12)
- Use workspace 1 for browsers with findings
- Workspace 2 for Emacs with notes
- Quick Org-capture (Mod+X) for documenting findings
