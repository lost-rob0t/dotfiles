#+TITLE: Lish Agentic Shell
#+AUTHOR: nsaspy
#+STARTUP: overview

* Contract

Lish is the default interactive shell surface. Bash remains the portable
login/recovery shim and immediately =exec=s Lish for ordinary interactive
terminals. Set =STAR_BASH_FALLBACK=1= to stay in Bash.  To also change the account's actual
login shell, run =lish-default-shell install=; =lish-default-shell restore=
returns it to Bash.

The shell keeps normal shell and Common Lisp execution native. Existing commands,
aliases, directories, ASDF commands, and Lisp forms stay on Lish's normal path.
Only otherwise-unknown/free-form lines are intercepted and sent to Prolog-RLM.

* Runtime

- =scripts/lish= launches Lish inside SBCL and accepts =-l/--login=.
- =scripts/lish-default-shell= explicitly installs/restores Lish as the account
  login shell on ordinary Unix hosts. It is never run implicitly by Home Manager.
- =scripts/lish-bootstrap= installs Quicklisp when needed and synchronizes pinned
  Yew/Lish, LISA, and Prolog-RLM source revisions.
- =.config/lish/init.lisp= loads optional expert runtimes and the agentic layer.
- =.config/lish/agentic.lisp= owns the Lish command UX and free-form evaluator.
- =scripts/lish-rlm= is the Prolog-RLM boundary.
- =scripts/lish-expert= exposes repo-local expert discovery/tests/explicit queries.
- =nix/home-manager/mods/lish.nix= packages the commands for desktop Home Manager.
- =bootstrap-termux.org= installs the same command/config surface on Termux.

LISA remains a Common Lisp Rete expert system inside the same Lisp image.
Dotfiles' =.zara/experts/= tree remains the canonical repo-local Prolog expert
library. Prolog-RLM remains the execution/authority runtime; the LLM does not get
an unrestricted Lisp or Prolog evaluator merely because the shell is agentic.

* Native commands

| Command | Purpose |
|---------+---------|
| =ai ...= | Free-form request; generate answer/shell/Lisp/one-liner output. |
| =ask ...= | Question answering through Prolog-RLM. |
| =agent ...= | Agentic task under Prolog-RLM capability/budget/effect boundaries. |
| =shell ...= | Generate shell commands. |
| =lisp ...= | Generate Common Lisp for the current image. |
| =oneliner ...= | Generate a compact one-liner. |
| =agentic on|off|toggle|status= | Control automatic free-form routing. |
| =rlm-mode direct|symbolic|symbolic-recursive|auto= | Select reasoning strategy. |
| =experts= | List repo-local experts. |
| =expert ...= | Invoke the expert CLI. |
| =expert-status= | Inspect expert runtime wiring. |
| =lisa-status= | Confirm the LISA package is loaded. |
| =lish-default-shell status|install|restore= | Inspect or explicitly change the account login shell. |

Unknown natural-language input behaves like =ai=. Known commands still execute
normally, so =git status=, =cd=, pipelines, Lisp functions, and ordinary Lish
builtins do not take an LLM detour.

* Termux

=bootstrap-termux.sh= installs SBCL and SWI-Prolog natively, installs the Lish
wrappers from the dotfiles checkout, warms the pinned Lish/LISA/Prolog-RLM
runtime, and links the canonical Bash config. This makes Termux use the same
default interactive shell contract without hard-coding desktop paths.

Nix and glibc-only tools can still cross the existing =platform-enter= boundary.
The shell itself stays native in Termux.
